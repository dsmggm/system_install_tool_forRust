# 硕科斯系统安装工具 V2.0.0（sks_installer）

> 在 Windows / WinPE 环境下，把 `install.wim`、`install.esd`、系统安装 ISO 或 GHO 备份部署到硬盘的图形化工具。附带**规划分区**、**应答文件优化**、**方案保存/加载**与**无人值守自动还原**。

> ⚠️ **请先读这段**：本工具会真实修改磁盘。「规划分区」执行时第一步就是 `diskpart clean`，**会清空整块硬盘的所有分区和数据**；保存出来的方案 `.bat` 也是可直接运行的还原脚本，双击即执行分区、格式化、写系统，且**没有二次确认**。操作前请确认目标盘、备份重要数据。

---

## 一、程序简介

| 项目 | 说明 |
|---|---|
| 名称 | 硕科斯系统安装工具（`sks_installer.exe`），版本 2.0.0 |
| 平台 | Windows x64（在 Windows PE 中使用时，PE 需带 `explorer.exe` 以支持 ISO 挂载） |
| 技术栈 | Rust + FLTK 1.4，单文件 GUI，无需安装、无需 .NET/VC 运行库 |
| 支持的安装源 | `*.iso`、`install.wim`、`install.esd`、`*.gho` |
| 依赖的外部命令 | 系统自带 `dism` / `diskpart` / `format.com` / `bootsect` / `bcdboot` / `reg.exe` / `shutdown`；GHO 模式另需 `ghost64.exe`；ISO 挂载还需要 `explorer.exe` |
| 配置文件 | exe 同目录 `config.ini`（首次启动自动生成） |
| 日志文件 | exe 同目录 `log\debug.log`（DEBUG 级，按天滚动，保留 30 天） |

**主要功能**

- **镜像部署**：`dism /apply-image` 应用 WIM/ESD，自动格式化、修复引导（`bootsect` + `bcdboot`）；ISO 自动挂载并定位 `sources\install.wim|esd`。
- **GHO 还原**：Ghost 硬盘还原 / 分区还原，自动处理中文路径（8.3 短名或临时副本），分区还原后修复引导。
- **规划分区**：GPT / MBR、ESP、MSR、1–8 个数据分区，支持「剩余空间自动均分」；**先预览暂存、安装时才写盘**，可一次规划多块硬盘。
- **自动部署与系统优化**：部署 `unattend.xml`，首次登录时自动完成高性能电源计划、关闭休眠/快速启动、显示桌面图标、跳过 OOBE 联网要求、创建本地管理员账户、暂停 Windows 更新 7 天等。
- **调试工具 / 自定义脚本**：把工具目录带到新系统桌面，并在首次登录时执行你自己的 `run_after.bat`。
- **方案文件**：把整套设置保存成一个 `.bat`，既能被本程序加载还原界面，也能脱离程序独立执行。
- **自动还原**：设定倒计时后无人值守重装（跳过确认对话框）。

## 二、运行前提与快速开始

1. **右键 `sks_installer.exe` →「以管理员身份运行」**。程序本身不检查也不自动申请管理员权限；没有提权时读取磁盘信息仍可用，但分区/格式化/引导修复会失败并提示 **Windows 错误 740**。
2. 首次启动会在 exe 同目录生成 `config.ini`（默认 `theme_mode = auto`，即跟随系统深浅色）。
3. 界面左上显示「自动还原 · 已停止」，窗口标题尾部显示当前状态（就绪 / 正在挂载 ISO… / 规划分区(n/n) 等）。
4. 点击右上角「显示日志」可展开实时日志面板；排错时也可直接看 `log\debug.log`。

调试开关：命令行执行 `sks_installer.exe --dump-disks` 会输出磁盘枚举 JSON 后退出、不启动 GUI（用于核对磁盘识别）。

## 三、界面导览

```
┌─ 自动还原开关 · 倒计时 ────────────────── 显示日志 │ 明亮/深色 ─┐
│ 磁盘与分区          │ 安装源        路径 + 浏览...                 │
│  磁盘 0: xxx [512GB]│               镜像（版本下拉）               │
│    └ 分区子行       │ 目标位置      系统安装硬盘 + 分区预览          │
│    [规划分区]       │ GHO 还原选项  还原模式 / 目标 / Ghost 路径      │
│    (预览) …         │ 安装选项      5 行复选框（见下表）             │
├─ 进度条 ── 当前方案：无 ── 保存当前方案 │ 加载方案 │ 开始安装 ─────┤
│ （可展开）运行日志面板                                              │
└──────────────────────────────────────────────────────────────────┘
```

**左列「磁盘与分区」**：树里每块硬盘一行，行右侧有行内「规划分区」按钮（只出现在硬盘行，分区行没有）。分区子行始终展开、不显示折叠箭头，点击行不会选中高亮。暂存分区方案后，树里会出现 `(预览)` 开头的 ESP / MSR / 数据分区条目。

**右列「安装选项」5 行（WIM/ISO 模式）**

| 行 | 控件 | 默认 | 说明 |
|---|---|---|---|
| 1 | 「格式化目标分区」「修复引导」「安装完成后重启」 | 格式化未勾；修复引导、重启已勾 | 与安装流程直接相关，始终可用 |
| 2 | 「禁用 Windows Defender」「关闭 Windows 防火墙」 | 未勾 | Defender 走离线注册表，不依赖应答文件 |
| 3 | 「自动部署与系统优化」+「用户名」 | 未勾；用户名 `admin` | 应答文件主开关，用户名用于创建本地管理员账户 |
| 4 | 「复制调试工具到桌面」+ 源目录 + 「浏览...」 | 未勾；路径为空 | 源目录需在界面选择 |
| 5 | 「进系统后执行脚本」 | 未勾 | 只有一个复选框，脚本路径在 `config.ini` 里配置 |

**GHO 模式**下第 2–5 行替换为：「还原后自动重启」「分区还原后修复引导」（两者默认勾选）。

**页脚**：进度条、「当前方案」完整路径（一行放不下时自动折行，鼠标悬停可看完整路径）、`保存当前方案`、`加载方案`、`开始安装`（条件不满足时灰色，安装中变成「停止安装」）。

## 四、动手前必须知道的 4 个概念

### 1. 规划分区是「暂存预览」，不点开始安装就不会动盘
点「规划分区」→ 在对话框里设好 → 点「保存」，只是把方案记在内存里并在树上显示 `(预览)`。真正执行 `diskpart`（`clean` → `convert gpt|mbr` → `create partition` → `format`）发生在点「开始安装」之后的**阶段 1**。可反复打开对话框修改，同一块盘的新方案会覆盖旧方案；多块盘依次规划即可累积。

### 2. 镜像相关选项只有在加载安装镜像后才可勾
界面启动时，第 2–5 行的 5 个复选框连同调试工具路径框、「浏览...」、用户名输入框/标签**全部置灰且取消勾选**。只有成功加载 `*.iso`、或文件名恰好为 `install.wim` / `install.esd` 时才放开，并自动勾选「自动部署与系统优化」「复制调试工具到桌面」。普通命名的 `xxx.wim` / `xxx.esd` 仍会被置灰。切换/加载失败、加载的方案里镜像已失效时，也会重新置灰。

### 3. 「自动部署与系统优化」是三项功能的前提
勾选「关闭 Windows 防火墙」「复制调试工具到桌面」「进系统后执行脚本」中的任意一项，都会**自动补勾**「自动部署与系统优化」：

- 防火墙靠应答文件里的 `%disable_firwall%` 占位符下发；
- 调试工具先复制到新系统的 `Windows\panther\TestTools`，要靠首次登录脚本搬到桌面；
- 自定义脚本由应答文件生成的 `unattend-01.cmd` 调用。

「禁用 Windows Defender」不在此列——它在应用镜像后通过离线注册表禁用，不依赖应答文件。

### 4. 两种持久化，别混用
| | `config.ini`（全局） | 方案 `.bat`（单套任务） |
|---|---|---|
| 写入方式 | 选项变更即时落盘；也可手工编辑 | 点「保存当前方案」生成 |
| 内容 | 所有开关初值、工具源目录、`run_after` 脚本路径、主题、倒计时、方案路径 | 安装源/索引、目标盘、分区方案、各复选框、用户名、GHO 设置 |
| 特点 | **不随方案走**：换机器加载方案后，工具源目录和 `run_after` 路径要重新配置 | 既是界面配置，也可脱离本程序独立运行（危险，见上文） |

## 五、使用教程

### 场景 1：用 ISO / WIM / ESD 全新安装（最常用）

1. **以管理员身份运行**程序。
2. **（可选）规划分区**：在左列目标硬盘行点「规划分区」。
   - 「分区表格式」：UEFI 机器用 `GPT (UEFI)`（默认），老 BIOS 用 `MBR (BIOS)`（切到 MBR 会自动取消并禁用 ESP）。
   - 「EFI 分区 (ESP)」：默认勾选、300 MB，文件系统 FAT32。
   - 「分区数量」：1–8（默认 1）；每行可填大小、单位（MB/GB）与文件系统（ntfs / fat32 / exfat / refs）。
   - **大小留空 = 自动分配剩余空间**：多个留空行会均分剩余；全部手填而有剩余时，剩余并入最后一个分区。超容量会红字提示「空间不足」并阻止保存。
   - 点「保存」→ 树里出现 `(预览)` 条目。**此时磁盘未被修改。**
3. **选择安装源**：「安装源」→「浏览...」选 ISO 或 `install.wim` / `install.esd`。
   - ISO 会通过资源管理器挂载，自动查找 `X:\sources\install.wim|esd`；找不到会提示并卸载。
   - `dism /get-imageinfo` 读取版本列表后填入「镜像」下拉（如 `1: Windows 11 Pro`），**选择要安装的版本/索引**。
   - 加载成功后，原本置灰的选项变为可用，并自动勾上「自动部署与系统优化」「复制调试工具到桌面」。
4. **确认目标位置**：在「系统安装硬盘」选择目标盘（有分区预览时会自动选中该盘）。GPT 下默认推导为引导分区 `盘号:0`、系统分区 `盘号:2`；MBR 下两者都是 `盘号:0`。下方会显示分区预览。
5. **设置安装选项**：
   - 全新安装建议勾「格式化目标分区」；「修复引导」保持勾选；按需决定「安装完成后重启」。
   - 「用户名」决定新系统创建的本地管理员账户名（默认 `admin`，空密码）。
   - 需要工具就填「复制调试工具到桌面」旁的源目录；需要首次登录跑自己的脚本就勾「进系统后执行脚本」（路径见场景 4）。
   - 按需勾「禁用 Windows Defender」「关闭 Windows 防火墙」。
6. 页脚「开始安装」由灰变亮后点击 → 阅读确认框（会列出镜像、索引、格式化、修复引导、防火墙、进系统后执行脚本，并警告**清空目标分区数据**）→ 确认。
7. **执行阶段**：规划分区写盘 → 格式化 → DISM 应用镜像 →（可选）离线禁用 Defender → 修复引导 → 部署应答文件/复制工具 → 完成。
8. **完成后**：勾选了重启时弹出「系统安装完成」倒计时对话框（默认 30 秒，可「立刻重启」或「取消」）；未勾选则询问是否立即重启。首次进入桌面时 `FirstLogon.ps1` 自动完成电源/桌面图标等优化、把 `TestTools` 搬到桌面、并调用你的 `run_after` 脚本。

### 场景 2：GHO 备份还原

1. 「浏览...」选 `*.gho` → 界面自动切换到 GHO 模式（隐藏镜像索引、WIM 选项组，显示 GHO 选项）。
2. 选「还原模式」：
   - **硬盘还原**（默认）：在「目标硬盘」下拉选整块盘，对应 `-clone,mode=load,...dst=N`。
   - **分区还原**：在「目标分区」下拉选具体分区，对应 `mode=pload,src=xxx:1,dst=N:P`。目标若是 `(预览)` 条目，会先执行规划分区再还原。
3. 确认「Ghost 路径」（默认 `%ProgramFiles(x86)%\ghost\ghost64.exe`，可编辑）。镜像/Ghost 路径含中文时程序会自动转换 8.3 短名或建临时副本，无需手工改名。
4. 「分区还原后修复引导」默认勾选（只跑 `bcdboot`，因为 GHO 保留原引导扇区）；「还原后自动重启」按需。
5. 点「开始安装」。失败时会显示 Ghost 返回码、输出前 500 字与 `debug.log` 末尾，便于排查。

> GHO 流程不走 WIM 的应答文件优化阶段，因此「自动部署」「复制工具」「进系统后执行脚本」在 GHO 模式下不生效。

### 场景 3：保存 / 加载方案

- **保存**：把界面全部设置调好 → 点「保存当前方案」→ 选路径、文件名（默认取当前方案名）→ 生成 `.bat`。文件名**不用手动敲 `.bat`**，没写后缀时程序会自动补上（已写成 `.BAT` 等大小写形式则原样保留）。页脚「当前方案」显示**完整路径**（过长时按宽度自动折成 2~3 行，极长路径可悬停查看完整内容），路径写入 `config.ini` 的 `plan_path`。
- **文件构成**：开头 `@echo off` + `chcp 65001`，中间是 `:: ===== SKS PLAN BEGIN/END =====` 元数据注释块（`:: key=value`），后面是可直接运行的 diskpart / dism / bcdboot / Ghost 命令段。
- **加载**：点「加载方案」选 `.bat` → 自动恢复安装源、镜像索引、目标盘、分区预览、全部复选框、用户名、GHO 设置；旧方案缺字段会用默认值补齐（如 `auto_repair_boot=1`、`admin_username=admin`、`ghost_path` 默认值、`run_after=0`）。当前机器上已不存在的物理盘方案会被过滤掉。
- **方案失效提示**：加载后只要改动任何界面设置，「当前方案」就会变成「无」，表示界面与方案文件已不一致，需要重新保存。
- ⚠️ 再次强调：**方案 .bat 是可执行脚本**，其中含 `clean` 和 `format quick`，不要在正常系统里双击试运行。

### 场景 4：调试工具与「进系统后执行脚本」

界面上「进系统后执行脚本」只有复选框，路径在 **exe 同目录 `config.ini`**：

```ini
run_after = %USERPROFILE%\Desktop\TestTools\run_after.bat
run_after_enabled = false
```

- `run_after`：要执行的脚本/程序路径，留空会回退到上面的默认值（避免把空命令写进应答文件）。
- `run_after_enabled`：界面复选框的上次状态（勾选时自动写回）。
- 勾选后，程序把占位符替换为
  `if exist "<路径>" start "" /wait "<路径>"`；`if exist` 保证脚本不存在时不会中断首次登录流程。
- 典型配合：勾「复制调试工具到桌面」，让工具目录随系统落到桌面 `TestTools`，然后默认脚本正好指向 `TestTools\run_after.bat`。
- 「自动部署与系统优化」必须勾上（勾选这项时会自动补勾），否则应答文件不部署，脚本不会执行。

### 场景 5：自动还原（无人值守重装）

1. 先按场景 1/2 配好并**保存方案**（`plan_path` 会被记录），且已选择安装源。
2. 勾页头「自动还原」开关（未选镜像会提示「请先选择镜像文件再开启自动还原」并回退）。
3. 标签变为「自动还原 · 运行中」，按 `countdown_sec` 倒计时（默认 **60 秒**），到点后自动加载方案、加载镜像并执行安装，**跳过确认对话框**。
4. 若 `config.ini` 里 `restore_enabled = true` 且 `plan_path` 有效，下次启动程序会自动重新开启该倒计时。

> 两个倒计时别混淆：`countdown_sec = 60` 是**自动还原开始前**的倒计时；`restart_countdown_sec = 30` 是**安装完成后重启**的倒计时。

### 主题与日志

- 右上主题按钮在「明亮 / 深色」两档间切换，点击后会把 `light` / `dark` 写回 `config.ini`，**离开 auto 模式**。`auto` 只在启动时读一次注册表 `HKCU\...\Themes\Personalize\AppsUseLightTheme`（0 = 深色，其它/读不到 = 明亮），运行中改系统主题不会实时跟随，需重启程序。
- 「显示日志」展开实时日志面板（按级别着色）；完整日志在 `log\debug.log`，按天滚动保留 30 天。排查「为什么选项是灰的」「脚本没执行」「分区失败」时先看这里。

## 六、`config.ini` 配置速查

文件在 exe 同目录，单段 `[settings]`，`key = value`，布尔值写 `true` / `false`。程序每次保存都会重写整个文件；非法主题值会被自动修正为 `auto`。

| 键 | 默认值 | 作用 |
|---|---|---|
| `restore_enabled` | `false` | 启动时是否开启自动还原倒计时 |
| `countdown_sec` | `60` | 自动还原倒计时秒数 |
| `plan_path` | 空 | 上次保存/加载的方案 `.bat` 路径（启动时静默加载） |
| `auto_restart` | `true` | 「安装完成后重启」/「还原后自动重启」初值 |
| `copy_tools` | `false` | 「复制调试工具到桌面」初值 |
| `deploy_unattend` | `false` | 「自动部署与系统优化」初值 |
| `disable_defender` | `false` | 「禁用 Windows Defender」初值 |
| `disable_firewall` | `false` | 「关闭 Windows 防火墙」初值 |
| `tools_source_path` | 空 | 调试工具源目录（**不随方案保存**，留空时跳过复制且不算失败） |
| `restart_countdown_sec` | `30` | 安装完成后自动重启的倒计时秒数 |
| `theme_mode` | `auto` | `auto` / `light` / `dark` |
| `run_after` | `%USERPROFILE%\Desktop\TestTools\run_after.bat` | 进系统后执行的脚本路径，**界面不显示、不随方案保存** |
| `run_after_enabled` | `false` | 「进系统后执行脚本」勾选态 |

> 手工改 `config.ini` 后需重启程序才生效。`theme_mode` 之外的设置多数也会在界面操作时被覆盖写回。

## 七、常见问题排查

| 现象 | 原因 / 处理 |
|---|---|
| 分区/格式化失败，提示「错误 740，请求的操作需要提升」 | 没有管理员权限。右键 exe「以管理员身份运行」；程序不会自动提权。 |
| 防火墙/Defender/自动部署/复制工具/执行脚本全是灰的、点不动 | 尚未加载安装镜像。选 `*.iso` 或文件名**恰为** `install.wim` / `install.esd` 的文件；普通 `xxx.wim` 不放开。置灰时同时取消勾选，加载后需重新勾。 |
| ISO 加载提示「在 ISO 中未找到 install.wim 或 install.esd」 | ISO 里没有 `sources\install.wim|esd`（例如纯 PE 盘）。换标准系统安装 ISO。 |
| ISO 挂载失败 / 一直停在「正在挂载 ISO」 | 依赖 `explorer.exe` 挂载；WinPE 需带资源管理器组件，或改用已解出的 `install.wim`。 |
| 调试工具在新系统桌面上找不到 | 先确认勾了「自动部署与系统优化」（工具靠首次登录脚本从 `Windows\panther\TestTools` 搬到桌面），再确认 `tools_source_path` 非空且目录存在。 |
| `run_after` 脚本没执行 | 检查：① 界面勾了「进系统后执行脚本」；② 自动部署已勾；③ `config.ini` 的路径正确且脚本确实随工具/镜像带到新系统；④ 看 `FirstLogon.log`。 |
| 点了「规划分区」但磁盘没变化 | 正常：这只是暂存预览。执行发生在点「开始安装」之后。 |
| 规划分区里 ESP 大小框/单位是灰的 | 对话框初始把这两个控件置为禁用，切换一次 GPT/MBR 或重新点一下「EFI 分区 (ESP)」复选框即可编辑；不改动时按默认 300 MB 生效。 |
| 「开始安装」一直灰色 | 缺少镜像/镜像索引，或既没选目标硬盘也没有分区预览；GHO 模式则检查目标下拉是否为空。 |
| GHO 中文路径报失败 | 程序会自动用 8.3 短名或同目录临时副本；若仍失败，看提示里的 Ghost 输出与 `debug.log`，或临时把镜像放到纯英文路径。 |
| 主题永远不跟随系统 | 检查 `theme_mode` 是否为 `auto`；点过主题按钮会写死 `light`/`dark`。`auto` 只在启动时判定一次，改完系统主题要重启程序。 |
| 加载方案后选项又变灰 / 勾选丢了 | 方案里的镜像路径已失效，或该盘已被拔出；重新选择镜像/目标盘即可。 |
| 想看详细执行过程 | 点「显示日志」，或直接打开 `log\debug.log`（含外部命令输出）。 |

## 八、附录

### A. WIM/ISO 安装的阶段顺序

| 阶段 | 内容 | 主要命令 |
|---|---|---|
| 1 | 执行暂存的规划分区（有才执行），刷新磁盘信息 | `diskpart /s`，含 `clean`、`convert gpt|mbr`、`create partition efi/msr/primary`、`format quick`、`assign letter` |
| 2 | 格式化系统分区（可选） | `format X: /fs:ntfs /q /y` |
| 3 | 应用镜像（进度 20–85%） | `dism /apply-image /imagefile:... /index:N /applydir:X:\ /verify`（ESD 加 `/checkintegrity`） |
| 4 | 禁用 Defender（可选，失败仅告警） | `reg load HKLM\mount ...` 修改服务 `Start=4` / `DisableAntiSpyware=1` |
| 5 | 修复引导（默认） | `bootsect /nt60 ... /force /mbr` + `bcdboot X:\Windows /s ... /f all` |
| 6 | 系统优化（勾选相关项时） | 写入 `X:\Windows\panther\unattend.xml` 并同步到 `System32\sysprep\panther`；复制工具到 `Windows\panther\TestTools` |
| 7 | 完成 / 重启 | `shutdown /r /t 0`（倒计时或询问后） |

**应答文件（首次登录自动做的事）**：高性能电源计划、关闭睡眠/休眠/快速启动、USB 选择性暂停、显示桌面图标、跳过 OOBE 联网要求（`BypassNRO`）、暂停 Windows 更新 7 天、创建 `%username%` 本地管理员账户、关闭防火墙（勾选项）、把 `TestTools` 移到桌面、执行 `%run_after%`。模板已编译进 exe，若 exe 同目录放置了 `unattend.xml` 则优先使用外置模板。

### B. 外部命令清单

`dism`、`diskpart`、`format.com`、`bootsect`、`bcdboot`、`reg.exe`、`explorer.exe`（ISO 挂载）、`shutdown`、`ghost64.exe`（仅 GHO）。全部为系统自带或需自行提供，程序不打包；子进程窗口自动隐藏。

### C. 构建与分发（开发者）

```bash
cargo test            # 发布前必须全绿
cargo build --release # 产物 target/release/sks_installer.exe
```

分发时把 `sks_installer.exe` 单独拷出即可；`config.ini` 会在新目录重新生成。若连同旧 `config.ini` 一起打包，注意 `theme_mode` 与 `plan_path` 可能是上次运行的值（`plan_path` 指向不存在的方案会被忽略）。调试构建可用环境变量 `SKS_UI_VIEWPORT=1366x768` 或 `800x600` 指定窗口尺寸复核两种布局。
